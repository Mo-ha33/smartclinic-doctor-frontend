# SmartClinic — واجهة الدكتور (نموذج تجريبي)

شاشة الدكتور (مالك العيادة): «شغلي» و«إدارة العيادة».

هذا نموذج شاشة واحد (ملف `index.html` فيه Tailwind و lucide) علشان نشوف التصميم ونجرّبه. **مفيش باك إند ومفيش سيرفر بيانات.**

## إزاي تفتحه

```
python -m http.server 8085
```

وبعدين افتح: http://localhost:8085/

الصفحة بتفتح تلقائيًا على دور **doctor** (بيتحط `?as=doctor` لوحده لو مش موجود).

## ملاحظات

- كل البيانات **تجريبية (Demo)** ومفيهاش بيانات مرضى حقيقية.
- محتاج إنترنت وقت الفتح علشان Tailwind و lucide بيتحملوا من CDN.
- فولدر `patches/` فيه سكريبتات بايثون اللي اتبنى بيها الملف، بالترتيب في `patches/ORDER.txt` (آخر واحد `patch_role_doctor9.py` في ريبو الدكتور).
